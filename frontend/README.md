
  # AIScope Frontend

  React + Vite frontend for the AI Visibility Tracking Platform.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Via `docker compose up` from the repo root, the frontend is served at http://localhost:3001 and talks to the API at http://localhost:8001 (see `.env` / `VITE_API_URL`).
